# Phased Budget Roadmap

## Phase 0: Free Foundation

Target: now

Monthly spend cap: **0-10 EUR**

Goal: connect the system using mostly free/local tools.

Allowed:

- GitHub repos
- GitHub Actions within free limits
- local Python scripts
- local Markdown planning
- small LLM API tests

Not allowed:

- paid workflow automation
- paid video subscriptions
- paid cloud rendering
- paid observability platforms

Exit criteria:

- `de-ai-newsletter` produces useful signals
- `research-analyser` has at least 2 useful reports
- `ai-video-studio` has at least 4 video drafts
- first revenue offer is written

## Phase 1: Earn First

Target: first 1-2 months

Monthly spend cap: **25 EUR**

Goal: create income with the least tooling possible.

Revenue focus:

1. AI data-readiness audit offer
2. Freelance/consulting micro-offer
3. 1 useful video/week
4. Research report that can become a post or lead magnet

Allowed:

- LLM API spend up to 15 EUR/month
- local video rendering
- GitHub Actions
- no paid SaaS unless urgent

Exit criteria:

- at least 1 paid conversation or client lead
- at least 4 published pieces of content
- one offer page or PDF
- monthly revenue reaches 100+ EUR or there is a concrete client pipeline

## Phase 2: Controlled Upgrade

Target: after early revenue signal

Monthly spend cap: **50-75 EUR**

Only start this after Phase 1 exit criteria.

Allowed upgrades:

- cheap VPS or self-hosted n8n if always-on automation is needed
- higher LLM API budget for production research/content
- simple domain or landing page tools

Still avoid:

- expensive creator suites
- managed agent platforms
- paid rendering unless videos become regular

Exit criteria:

- 500+ EUR/month revenue or repeatable lead generation
- one workflow clearly saves 5+ hours/month
- content cadence is stable

## Phase 3: Productization

Target: once income is repeatable

Monthly spend cap: **100-200 EUR**

Allowed:

- production hosting
- managed database/vector store
- paid rendering if content volume justifies it
- observability/evals if agents are used with real customers

Exit criteria:

- SaaS or consulting system is producing repeatable revenue
- tooling spend is less than 10-15% of monthly side-income

## Spending Gates

Before paying for a tool, answer:

1. Which bottleneck does this remove?
2. How many hours/month will it save?
3. Which repo/workflow depends on it?
4. Is there a free/local alternative?
5. Can this wait until revenue appears?

Default answer: wait.
